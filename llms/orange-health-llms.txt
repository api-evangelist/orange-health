# Orange Health Labs — Partner API

> Orange Health Labs is an Indian at-home diagnostics lab (Bengaluru, Delhi,
> Gurgaon, Noida, Hyderabad) offering 60-minute home sample collection and
> 6-hour reporting. The Partner API lets partners check serviceability, create
> home-collection / lab-drop-off / camp orders, track order status, reschedule,
> cancel, add-on tests, pull structured results, and receive HMAC-signed
> lifecycle webhooks. Auth is an api_key request header.

## APIs
- [Partner API (Apiary docs)](https://orangehealth.docs.apiary.io/): Public order-flow documentation.
- Production base URL: https://partner-api.orangehealth.in

## Operations
- GET /v1/partner/serviceability — fetch serviceability + slots
- POST /v1/partner/order — create order (home collection / lab drop-off)
- POST /v1/partner/camp/{campID}/order — create camp order
- GET /v1/partner/order-details/{requestID} — order status
- GET /v1/partner/test-results — structured test results (<=7-day window)
- POST /v1/partner/{requestID}/add-on-order — add tests/packages
- PATCH /v1/partner/{requestID}/reschedule — reschedule
- PATCH /v1/partner/{requestID}/cancel — cancel (async)
